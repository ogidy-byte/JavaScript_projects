# JavaScript Practice Projects 🚀

Welcome to my JavaScript Practice Repository! This repository contains a collection of mini-projects, coding challenges, and algorithm exercises that I have built while learning and refining my JavaScript skills. 

Each file is a standalone script designed to solve a specific problem or demonstrate a particular programming concept (such as loops, conditionals, functions, and string manipulation).

## 📂 Project Directory

Here is a breakdown of the scripts included in this repository:

| File Name | Description |
| :--- | :--- |
| **`beerLyrics.js`** | A script that generates and prints the lyrics to the classic "99 Bottles of Beer" song using loops. |
| **`bmi_calculator.js`** | A simple calculator that computes a user's Body Mass Index (BMI) based on height and weight inputs. |
| **`capitalizing.js`** | A utility script designed to capitalize the first letter of a given string or an array of words. |
| **`dog_age_converter.js`** | A function that converts human years into equivalent "dog years". |
| **`fibonacciGen.js`** | A generator that outputs the Fibonacci sequence up to a specified number of terms. |
| **`fizzBuzz.js`** | The classic FizzBuzz programming challenge using standard conditional logic. |
| **`fizzBuzz_2.js`** | An alternative implementation of FizzBuzz utilizing a `while` loop. |
| **`fizzBuzz_3.js`** | Another variation/optimization of the FizzBuzz challenge utilizing the `for` loop. |
| **`guestList.js`** | An array manipulation exercise for confirming if one is part of the list of guests. |
| **`isLeapYear.js`** | A function that determines whether a given year is a leap year based on the Gregorian calendar rules. |
| **`isLeapYear2.js`** | An alternative approach to solving the leap year algorithm.(extended version) |
| **`loveCalculator.js`** | A fun, beginner-friendly script that calculates a "love compatibility" percentage between two names. |
| **`number_of_bottles.js`** | A focused exercise on using simple Javascript to count down a number of bottles in order to tell the teller how many bottles of milk one is buying. |
| **`LICENSE`** | The open-source license for this repository. |

## 🛠️ Technologies Used

* **JavaScript (ES6+)**: All scripts are written in modern JavaScript.
* **Node.js / Browser Console**: These scripts can be executed using Node.js in the terminal or run directly in a browser's developer console.
